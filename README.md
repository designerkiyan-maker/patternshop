# 🧵 بات فروش الگوی خیاطی (فورک Shopvpn)

بات تلگرام فروش خودکار **الگوهای آماده‌ی خیاطی** — محصولات دیجیتال (فایل PDF و...) که بعد از تایید پرداخت، مستقیم داخل تلگرام برای خریدار ارسال می‌شوند.

بر پایه‌ی [Shopvpn](https://github.com/mehdirafatpanah/Shopvpn) (مجوز MIT) و بازنویسی‌شده برای فروش الگو.

## ✨ امکانات

- 🧵 **کاتالوگ الگو** — دسته‌بندی + محصولات با عکس پیش‌نمایش و یک یا چند فایل (PDF/راهنما) به‌ازای هر الگو؛ فروش نامحدود
- 💳 پرداخت کارت‌به‌کارت با تایید دستی ادمین (عکس/فایل رسید)
- 👛 کیف پول داخلی (شارژ با تایید ادمین، خرید آنی با موجودی)
- 🎟 کد تخفیف (درصدی/مبلغی با سقف استفاده)، 🎡 گردونه شانس، 🤝 زیرمجموعه‌گیری (پورسانت خرید / الگوی رایگان / شارژ هدیه)
- 🧪 الگوی نمونه رایگان برای هر کاربر (آپلود و مدیریت از پنل)
- 📥 دانلود مجدد فایل‌های خریداری‌شده از بخش «سفارش‌های من»
- 🎫 پشتیبانی/تیکت + چت زنده با ادمین آنلاین
- 👑 پنل مدیریت کامل داخل بات با ۴ سطح نقش (مالک/ادمین/میانی/پشتیبان)، لاگ فعالیت ادمین‌ها
- 🗄 بکاپ روزانه خودکار از دیتابیس + بازیابی از فایل
- 🎨 شخصی‌سازی کامل: متن دکمه‌ها، چیدمان منو، رنگ دکمه‌های شیشه‌ای، پیام خوش‌آمد — همه از پنل
- 📅 تاریخ شمسی، عضویت اجباری در کانال، مسدودسازی کاربر

## 🚀 راه‌اندازی

پیش‌نیاز: Python 3.10+

```bash
git clone <آدرس-این-ریپو> && cd <نام-پوشه>
python -m venv venv
source venv/bin/activate        # ویندوز: venv\Scripts\activate
pip install -r requirements.txt
```

فایل `.env` بساز (نمونه در `.env.example`):

```env
BOT_TOKEN=توکن_بات_از_BotFather
OWNER_ID=آیدی_عددی_تلگرام_مالک
```

اجرا:

```bash
python main.py
```

دیتابیس SQLite به‌صورت خودکار ساخته می‌شود؛ هیچ سرویس دیگری لازم نیست. برای اجرای دائمی روی سرور، یک سرویس systemd بسازید یا از `screen`/`nohup` استفاده کنید.

## 🛠 شروع کار (اولین قدم‌ها در بات)

1. `/start` بزن و از منوی مدیریت وارد **پنل مدیریت** شو.
2. **💳 تنظیم شماره کارت** — شماره کارت و نام صاحب حساب را ثبت کن (در صفحه پرداخت به مشتری نمایش داده می‌شود).
3. **📂 مدیریت دسته‌بندی‌ها** → دسته بساز (مثلاً «لباس زنانه»).
4. **📦 مدیریت محصولات** → افزودن محصول: نام → قیمت → توضیحات → عکس پیش‌نمایش → آپلود فایل(های) PDF.
5. (اختیاری) **📎 مدیریت فایل‌های الگو** → افزودن/حذف فایل یا تعویض عکس پیش‌نمایش هر محصول.
6. (اختیاری) **🧪 الگوی نمونه رایگان** → یک الگوی نمونه آپلود کن تا مشتری‌ها تست بگیرند.

محصولی که فایل نداشته باشد در فروشگاه «⛔️ ناموجود» نمایش داده می‌شود.

## 📲 Mini App (فروشگاه وب داخل تلگرام)

پوشه‌ی `miniapp/` یک فروشگاه وب کامل داخل تلگرام است: کاتالوگ با عکس پیش‌نمایش الگوها، سبد خرید با آپلود رسید کارت‌به‌کارت، کیف پول، دانلود مستقیم فایل‌های خریداری‌شده، زیرمجموعه‌گیری، گردونه شانس و پشتیبانی زنده.

راه‌اندازی (روی سرور با دامنه و SSL):

```bash
# در .env مقدار MINIAPP_URL را بگذار:
# MINIAPP_URL=https://shop.example.com
venv/bin/uvicorn miniapp.server:app --host 127.0.0.1 --port 8001
```

سپس پشت Nginx با SSL قرارش بده (پروکسی به 127.0.0.1:8001) و `MINIAPP_URL` را در `.env` ست کن و بات را ری‌استارت کن — دکمه‌ی «🛍 فروشگاه» هم در منوی بات و هم کنار باکس پیام ظاهر می‌شود. احراز هویت کاربران از طریق `initData` تلگرام و HMAC-SHA256 سمت سرور انجام می‌شود؛ تایید سفارش‌ها همچنان با همان دکمه‌های بات توسط ادمین انجام می‌شود.

## 🖥 پنل مدیریت وب مستقل (`admin_panel`)

پنل مدیریت کاملاً مستقل از تلگرام روی دامنه‌ی خودش: لاگین با یوزرنیم/پسورد، تایید سفارش‌ها و شارژ کیف پول از مرورگر، مدیریت محصولات و آپلود فایل‌های PDF و عکس پیش‌نمایش بدون تلگرام، داشبورد آمار فروش، مدیریت کدهای تخفیف/گردونه/زیرمجموعه‌گیری، تیکت‌ها، پیام همگانی، مدیریت وب‌ادمین‌ها با سطح دسترسی (۹ مجوز)، بکاپ/بازیابی، لاگ فعالیت ادمین‌ها و اعلان Push مرورگر.

```bash
# ساخت اولین حساب owner پنل وب
venv/bin/python -m admin_panel.create_admin <username> <password>

# اجرا (پشت Nginx با SSL روی پورت 8002)
venv/bin/uvicorn admin_panel.server:app --host 127.0.0.1 --port 8002
```

برای اعلان‌های Push مرورگر یک‌بار کلید VAPID بساز و در `.env` بگذار: `python -m admin_panel.generate_vapid_keys`

## 🚢 نصب روی سرور (پروداکشن، ایزوله)

همه‌چیز در `/opt/patternshop` نصب می‌شود (repo + venv مستقل + دیتابیس) و دو سرویس systemd اختصاصی می‌سازد — به بقیه‌ی سرور دست نمی‌زند:

```bash
git clone <آدرس-این-ریپو> && cd patternshop
sudo BOT_TOKEN=... OWNER_ID=... REPO_URL=<آدرس-این-ریپو> bash deploy/install_server.sh

# دامنه + SSL + فعال‌شدن دکمه‌ی فروشگاه:
sudo bash deploy/install_server.sh --domain shop.example.com
# پنل مدیریت وب (اختیاری):
sudo bash deploy/install_server.sh --panel panel.example.com
```

در کلادفلر (یا هر DNS دیگری) فقط یک رکورد **A** به **IP سرور** لازم است.

| `file_delivery.py` | تحویل فایل الگو به خریدار |

| `backup.py` / `jalali.py` / `force_join.py` / `blocked_user.py` / `fsm_storage.py` | زیرساخت مشترک |
